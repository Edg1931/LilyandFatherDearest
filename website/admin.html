About this dashboard

This is a frontend-only demo. All data is stored in your browser's localStorage, which means:

  • You can use it on your tablet at the counter today, but data does not sync between devices.
  • To make this multi-device (so the kitchen iPad and the front register share an order queue), the JavaScript would talk to a small backend (e.g. Cloudflare Workers + D1, Supabase, or Firebase). The structure of Store is designed so you can swap it for an API call without changing any of the customer pages.
  • The CSV exports work right now and produce a real spreadsheet that opens in Excel, Google Sheets, or Numbers.
